# sing-box REALITY Configuration Reference

| Variable | Default | Description |
|---|---|---|
| `SB_PORT` | `443` | Xray listen port. Use 443 to blend with HTTPS. |
| `SB_SNI` | `www.cloudflare.com` | REALITY destination — must be a real TLS 1.3 host with a matching cert. The server does not connect to it; it is only used for the handshake fingerprint. |
| `SB_UUID` | auto-generated | VLESS client UUID. Auto-generated by `uuidgen` if left blank. |
| `SB_SHORT_ID` | auto-generated | 8-byte hex identifier. Auto-generated by `openssl rand -hex 8` if left blank. |
| `SB_LOG_LEVEL` | `info` | sing-box log level: `debug`, `info`, `warning`, `error` |
| `SB_TUN_MTU` | `1400` | TUN interface MTU. Lower values help with fragmentation over restrictive networks. |

`SERVER_PUBLIC_IP` (shared) is used in client configs as the VLESS server address.

## Secret material (NOT in config.env)

| Item | Generated by | Stored in |
|---|---|---|
| `SB_REALITY_PRIVATE_KEY` | `xray x25519` in `server/configure.sh` | `singbox-reality/generated/secrets.env` |
| `SB_REALITY_PUBLIC_KEY` | derived from private key | `singbox-reality/generated/secrets.env` |

`secrets.env` is `chmod 600` and in `.gitignore`. `client/configure.sh` sources it to stamp client templates.

## Template placeholders → variables

| Placeholder | Source |
|---|---|
| `__SB_PORT__` | `SB_PORT` |
| `__SB_UUID__` | `SB_UUID` (or from `secrets.env`) |
| `__SB_SNI__` | `SB_SNI` |
| `__SB_SHORT_ID__` | `SB_SHORT_ID` (or from `secrets.env`) |
| `__SB_LOG_LEVEL__` | `SB_LOG_LEVEL` |
| `__SB_TUN_MTU__` | `SB_TUN_MTU` |
| `__SB_REALITY_PRIVATE_KEY__` | from `secrets.env` (server template only) |
| `__SB_REALITY_PUBLIC_KEY__` | from `secrets.env` (client templates) |
| `__SERVER_PUBLIC_IP__` | `SERVER_PUBLIC_IP` (shared) |

## Generated files (in `singbox-reality/generated/`, chmod 600, gitignored)

| File | Purpose |
|---|---|
| `xray-server.json` | Deployed to `/usr/local/etc/xray/config.json` |
| `singbox-android.json` | Import into SFA / sing-box Android |
| `singbox-ubuntu-client.json` | Deployed to `/etc/sing-box/config.json` |
| `secrets.env` | UUID, short_id, and REALITY keypair |
