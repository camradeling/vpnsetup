# WireGuard Configuration Reference

| Variable | Default | Description |
|---|---|---|
| `WG_INTERFACE` | `wg0` | WireGuard interface name |
| `WG_PORT` | `51820` | UDP listen port on the server |
| `WG_VPN_CIDR` | `10.66.66.0/24` | VPN network in CIDR notation |
| `WG_SERVER_VPN_IP` | `10.66.66.1` | Server's address inside the VPN |
| `WG_CLIENT_NAME` | `client1` | Label for the first client's config files |
| `WG_CLIENT_IP` | `10.66.66.2` | Client's address inside the VPN |
| `WG_DNS` | `1.1.1.1, 8.8.8.8` | DNS pushed to client via `DNS =` in `[Interface]` |
| `WG_ROUTING_MODE` | `3` | 1=server-only, 2=vpn-subnet, 3=full-tunnel, 4=custom |
| `WG_CLIENT_ALLOWED_IPS` | `0.0.0.0/0, ::/0` | Effective AllowedIPs on the client (computed from mode, or set directly for mode 4) |
| `WG_ENABLE_NAT` | `yes` | Write iptables MASQUERADE PostUp/PostDown into server config |
| `WG_ENABLE_PSK` | `yes` | Generate and include a PresharedKey |

`SERVER_PUBLIC_IP` (shared) is used as the client's `Endpoint` host.

## Generated files (in `wireguard/generated/`, chmod 600, gitignored)

| File | Content |
|---|---|
| `server_<iface>.conf` | Full server config including PrivateKey and all Peer blocks |
| `<client>_linux.conf` | Client config for Linux (wg-quick) |
| `<client>_android.conf` | Client config for Android import |
| `<client>_android.png` | QR code of the Android config |
| `client_linux.conf` | Canonical symlink copy used by `client/configure.sh` |
| `client_android.conf` | Canonical symlink copy |
| `server_wg0.conf` | Canonical copy used by `server/apply.sh` |

Keys are generated by `wg genkey` / `wg pubkey` / `wg genpsk` inside `server/configure.sh` and are never stored in `config.env`.
